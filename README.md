# Site de l'association Arraw n-Tlelli

## 1. Mettre le site en ligne gratuitement (GitHub Pages)

1. Créez un compte gratuit sur https://github.com si vous n'en avez pas.
2. Créez un nouveau dépôt (repository) public, par exemple nommé `arrawntlelli`.
3. Sur la page du dépôt, cliquez sur **Add file → Upload files**, puis glissez-déposez les 3 fichiers : `index.html`, `script.js`, et le dossier `assets` (avec votre logo).
4. Cliquez sur **Commit changes**.
5. Allez dans **Settings → Pages**.
6. Dans "Branch", choisissez `main` et le dossier `/ (root)`, puis **Save**.
7. Après 1-2 minutes, votre site sera visible à l'adresse :
   `https://VOTRE-NOM-UTILISATEUR.github.io/arrawntlelli/`

Aucun logiciel à installer, tout se fait depuis le site github.com.

## 2. Le logo

Le vrai logo est déjà intégré (`assets/logo.png`) — pensez à bien uploader
le dossier `assets` en entier sur GitHub, sinon le logo n'apparaîtra pas.
Si vous voulez le changer plus tard, remplacez simplement le fichier
`assets/logo.png` par une nouvelle image du même nom.

## 3. Ajouter un nouvel événement ou article

Ouvrez le fichier `script.js` — toutes les instructions sont en commentaire tout en haut.
En résumé : copiez un bloc existant, changez le titre/date/texte, enregistrez, puis
re-publiez sur GitHub (Add file → Upload files, ou modifiez directement le fichier
sur github.com avec le bouton crayon ✏️).

## 4. Activer les publicités (Google AdSense)

1. Une fois le site en ligne avec du contenu réel (attendez d'avoir publié plusieurs
   vrais articles), créez un compte sur https://adsense.google.com
2. Soumettez l'URL de votre site GitHub Pages.
3. Google vous donnera un code de vérification à coller dans `index.html`,
   dans la zone indiquée en commentaire en haut du fichier
   (« ESPACE PUBLICITAIRE — Google AdSense »).
4. L'approbation peut prendre de quelques jours à quelques semaines. Une fois
   approuvé, Google vous donnera un second code (bloc d'annonce) à coller dans
   la zone `<div class="ad-slot" id="ad-slot">` à la place du texte provisoire.

**Important** : Google AdSense refuse les sites vides ou avec trop peu de contenu.
Publiez au moins 5 à 10 vrais articles/événements avant de soumettre votre
candidature — cela augmente vos chances d'être accepté.

## 5. Autres façons de faire vivre le site

- Ajoutez régulièrement vos nouveaux événements pour garder le site actif (Google
  favorise les sites mis à jour régulièrement).
- Partagez le lien du site sur votre page Facebook et dans le groupe.
- Vous pouvez plus tard ajouter un vrai nom de domaine (ex. `arrawntlelli.dz` ou
  `.com`), généralement pour quelques euros par an — je peux vous expliquer
  comment faire le moment venu.
